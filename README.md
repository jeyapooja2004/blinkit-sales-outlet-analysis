# Blinkit Sales & Outlet Analysis Dashboard

## 📊 Project Overview

An interactive Power BI dashboard created to analyze Blinkit's sales performance and outlet characteristics.

The dashboard provides insights into sales based on item type, fat content, outlet size, outlet location, outlet type, and outlet establishment year.

## 📌 Key KPIs

- **Total Sales:** 1.20M
- **Average Sales:** 140.99
- **Number of Items:** 8,523
- **Average Rating:** 3.92

## 📈 Analysis Covered

- Sales by Item Type
- Sales by Fat Content
- Fat Content by Outlet
- Sales by Outlet Establishment Year
- Sales by Outlet Size
- Sales by Outlet Location
- Outlet Type performance
- Average Rating and Item Visibility by Outlet Type

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX

## 📂 Files

- `blinkit sales analysis.pbix` — Power BI dashboard file
- `blinkit sales pdf.pdf` — Dashboard export
